# Transferência visual do Agent Pixel

Agent Pixel é tratado somente como ferramenta de apoio visual. Não presuma que compartilha contexto, arquivos, memória, API ou canal de comunicação com Codex. As capacidades exatas de exportação dependem da instalação do Agent Pixel.

## Processo manual

1. Gere no Agent Pixel somente materiais que a ferramenta realmente disponibiliza e que não contenham credenciais ou dados pessoais desnecessários.
2. Exporte ou transcreva manualmente para o projeto os artefatos disponíveis: capturas ou protótipos, fluxos, dimensões, hierarquia, cores, tipografia, espaçamento, componentes, estados e comportamento responsivo. Se não houver exportação, registre a especificação textual e as referências visuais permitidas.
3. Informe no handoff a versão/data do material, tela ou fluxo, viewport, estados cobertos e decisões ainda abertas. Armazene arquivos no local acordado do projeto, nunca sobrescrevendo material existente sem aprovação.
4. Designer e solicitante revisam o material para validar intenção, conteúdo, acessibilidade e consistência com o produto.
5. Frontend implementa a especificação aprovada e documenta diferenças necessárias. QA compara a implementação com a referência em viewports e estados definidos, além de testar teclado, foco e leitor de tela.
